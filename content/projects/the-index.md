# The Index / Prescript Terminal

A productivity experiment that turns your daily to-do list into a mysterious terminal that hands out prescripts. Follow them well. It mixes task tracking with CRT effects and a lot of atmosphere, mostly because a plain checklist was never gonna keep me motivated.

**Stack:** JavaScript · PWA · UI
